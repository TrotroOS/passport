# User help & troubleshooting

End-user guide for when something goes wrong in Passport. The live version is at **`/help`** in the app (public — no sign-in required).

## Topics covered

| Issue | What to try first |
|-------|-------------------|
| Can't sign in | Correct email, invitation link, sign out/in |
| Document processing failed | Wait and refresh, PDF/image quality, re-upload |
| Shipment blocked / low score | Discrepancies, missing docs, workflow tasks |
| Verification discrepancies | Fix documents or shipment data, re-run verify |
| Regulatory checks failing | Upload required docs, re-run checks |
| Collaboration invite | Use email link, resend invite, sign up if external |
| Inbound email/WhatsApp | Settings → Channels, registered sender, shipment ref |
| API / webhooks | API keys, docs, webhook delivery logs |

## Contact support

- **In app:** Dashboard → **Feedback**, or **Help & troubleshooting** → **Still stuck?**
- **Email:** `trotroosapp@gmail.com` (override with `NEXT_PUBLIC_SUPPORT_EMAIL`)
